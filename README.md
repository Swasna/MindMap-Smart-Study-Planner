# MindMap – Smart Study Planner

## About the Project

MindMap is a C-based Smart Study Planner that helps students organize their subjects and topics based on difficulty level and the number of days remaining until an exam.

## Features

* Add subjects and topics.
* Set topic difficulty as Easy, Medium, or Hard.
* Enter the number of days remaining until the exam.
* Generate a priority-based study plan.
* View all added topics.
* Mark topics as completed.
* Save and load topic details using file handling.

## Technologies Used

* Programming Language: C
* Data Structure: Linked List
* Concepts: Structures, Pointers, File Handling, and Sorting

## How to Run

### Compile

```bash
gcc main.c -o main
```

### Execute

On Windows:

```bash
.\main.exe
```
